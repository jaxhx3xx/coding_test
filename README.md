# coding_test

백준과 프로그래머스에서 푼 문제들을 기록하는 공간입니다.

## 폴더 구조

```
coding_test/
├── 백준/
│   └── Bronze/          초창기 백준 풀이 (Java)
├── 프로그래머스/         BaekjoonHub 자동 커밋
│   ├── 0/               Level 0 (언어 문제)
│   ├── 1/               Level 1 (주로 SQL)
│   └── 2/               Level 2 (SQL)
└── archive/             초창기 여러 언어 시도 흔적
    ├── C/
    ├── Java/
    └── programmers/     Kotlin · Go · JavaScript · C++ 등
```

## About

- 프로그래머스 풀이는 [BaekjoonHub](https://github.com/BaekjoonHub/BaekjoonHub) 크롬 확장으로 자동 커밋됩니다.
- 현재는 프로그래머스 위주로 문제를 풀고 있습니다.
- `archive/`는 여러 언어를 시도해봤던 초창기 학습 기록입니다.
